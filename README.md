# preloop Homebrew tap

```sh
brew install preloopdev/tap/preloop
```

`Formula/preloop.rb` is generated by [cargo-dist](https://axodotdev.github.io/cargo-dist)
and pushed by the release workflow in
[preloopdev/preloop](https://github.com/preloopdev/preloop) on every stable
release. Do not edit the formula here — the next release overwrites it.

preloop is a local, self-hosted GitHub Actions control plane: the official
runner protocol, hardware-isolated microVM jobs, and a debug session for every
failed job. Docs and releases: <https://github.com/preloopdev/preloop>.
